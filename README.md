# Xenoviz Claude plugins

A Claude Code marketplace for the plugins and mods Xenoviz makes.

## Add the marketplace

```
/plugin marketplace add xenoviz/claude-plugins
```

## Plugins

| Plugin | What it does | Install |
| --- | --- | --- |
| [Tasklane](https://github.com/xenoviz/tasklane) | A task board pane beside a long session: tasks and their cost, usage by agent, standing rules, connected sessions. | `/plugin install tasklane@xenoviz` |

## Updating

```
claude plugin marketplace update xenoviz
claude plugin update tasklane@xenoviz
```

Restart Claude afterwards for the update to apply.
